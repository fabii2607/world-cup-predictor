# ⚽ World Cup 2026 Predictor

A full-stack Machine Learning project that predicts international football match outcomes and simulates the 2026 World Cup using historical match data, engineered team features, a trained ML model, a FastAPI backend, and a React frontend.

## Live Demo

* Frontend: https://world-cup-predictor-rouge.vercel.app
* Backend API Docs: https://world-cup-predictor-api.onrender.com/docs

> Note: The backend is hosted on Render's free tier and may take a few seconds to wake up on the first request.

## Project Overview

This project was developed to predict football match results and simulate a World Cup tournament through an end-to-end machine learning pipeline.

The system allows users to:

* Select two national teams and predict the match outcome
* View win/draw probabilities generated by a trained Machine Learning model
* Simulate the 2026 World Cup tournament
* Run group stage and knockout simulations
* Interact with a React-based frontend connected to a FastAPI backend
* Explore an interactive world map for team selection

## Model Features

The model uses engineered features such as:

* Average points in the last 5 matches
* Average goals scored
* Average goals conceded
* Goal difference
* Win streak
* Clean sheets
* Momentum score
* Elo rating
* Elo difference

## Model

The deployed model is a `GradientBoostingClassifier`, exported as a `.pkl` file and loaded by the FastAPI backend.

The backend receives two teams, builds the feature vector using the processed `team_strength.csv`, and returns a prediction with class probabilities.

Example response:

```json
{
  "prediction": "Home Win",
  "probabilities": {
    "Away Win": 0.23,
    "Draw": 0.28,
    "Home Win": 0.49
  }
}
```

## Backend API

The backend was built with FastAPI and deployed on Render.

### Production API

```text
https://world-cup-predictor-api.onrender.com
```

### API documentation

```text
https://world-cup-predictor-api.onrender.com/docs
```

### Main endpoint

```http
POST /predict
```

Example request:

```json
{
  "home_team": "Brazil",
  "away_team": "Argentina"
}
```

Example response:

```json
{
  "prediction": "Home Win",
  "probabilities": {
    "Away Win": 0.23,
    "Draw": 0.28,
    "Home Win": 0.49
  }
}
```

### Run the backend locally

```bash
cd backend
venv\Scripts\activate
python -m uvicorn app.main:app --reload
```

Local API documentation:

```text
http://127.0.0.1:8000/docs
```
