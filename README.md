# ⚽ World Cup 2026 Predictor

A full-stack Machine Learning project that predicts international football match outcomes and simulates the 2026 World Cup using historical match data, engineered team features, a trained ML model, a FastAPI backend, and a React frontend.

## Project Overview

This project was developed to predict football match results and simulate a World Cup tournament through an end-to-end machine learning pipeline.

The system allows users to:

- Select two national teams and predict the match outcome
- View win/draw probabilities generated by a trained model
- Simulate the 2026 World Cup tournament
- Run group stage and knockout simulations
- Interact with a React-based frontend connected to a FastAPI backend

1. Data collection and cleaning
2. Team-level metrics generation
3. Feature engineering

5. Model training
6. Model improvement and comparison
7. World Cup simulation
8. Model export

10. Frontend integration

## Model Features

The model uses engineered features such as:

- Average points in the last 5 matches
- Average goals scored
- Average goals conceded
- Goal difference
- Win streak
- Clean sheets
- Momentum score
- Elo rating
- Elo difference

## Model

The deployed model is a `GradientBoostingClassifier`, exported as a `.pkl` file and loaded by the FastAPI backend.

The backend receives two teams, builds the feature vector using the processed `team_strength.csv`, and returns a prediction with class probabilities.

Example response:

```json
{
  "prediction": "Home Win",
  "probabilities": {
    "Away Win": 0.23,
    "Draw": 0.28,
    "Home Win": 0.49
  }
}
```

## Backend API

### Run the backend locally

```bash
cd backend
venv\Scripts\activate
python -m uvicorn app.main:app --reload
```

API documentation:

```text
http://127.0.0.1:8000/docs
```

### Main endpoint

```http
POST /predict
```

Example request:

```json
{
  "home_team": "Brazil",
  "away_team": "Argentina"
}
```

Example response:

```json
{
  "prediction": "Home Win",
  "probabilities": {
    "Away Win": 0.23,
    "Draw": 0.28,
    "Home Win": 0.49
  }
}
```

## Frontend

The frontend allows users to interact with the prediction model through a visual interface.

Features include:

- Interactive world map
- Team selection
- Match prediction
- Win probability bars
- Group stage simulation
- Knockout stage simulation
- World champion simulation

### Run the frontend locally

```bash
cd frontend
npm install
npm run dev
```

Frontend URL:

```text
http://localhost:5173
```

## 2026 World Cup Simulation

The tournament simulator uses the defined 2026 groups and simulates:

- Group stage
- Round of 32
- Round of 16
- Quarterfinals
- Semifinals
- Final
- Champion

Each match is powered by the ML model through the FastAPI prediction endpoint.
